Deploying to Vercel

This application is 100% pre-configured for Vercel deployment with zero configuration:

  1. Deploy via Vercel CLI: 
    npm install -g vercel
vercel deploy --prod
  2. Deploy via GitHub / Git Repository:

    Push this directory to a GitHub repository, open vercel.com, import repository, and click Deploy. Vercel automatically detects vercel.json, packages the Python API in api/index.py, and serves the frontend from public/.
