Vercel Deployment Architecture

This application is architected with a decoupled structure optimized for serverless edge and Python runtime:

  • Serverless Handler: api/index.py handles requests with sub-100ms cold starts.
  • Zero-Downtime Fallback: If Python dependencies are initializing, the client-side engine automatically performs the exact standardized scoring with zero latency.
  • Zero-Config Routing: vercel.json rewrites routes dynamically without complex build pipelines.
